## 产品目标与已确认规则

- 新人投入 PDF、图片、CSV 或文本文件后，系统解析证据、生成简短梗概、归入1–5个关键且有标识性的较宽正式主题（按整篇累计，全库总数不限），再生成与主题对应的问答候选。每篇文字约3–5组、图片0–2组，合计目标5–7组中英双语知识点（10–14条六字段记录）；质量不足时说明原因，不编造补齐。
- 主题优先复用、合并同义、避免把每个关键词都建成正式主题；细分词单独用于模糊搜索。搜索应能由上位词发现相关主题及其实际涵盖文件，同时避免把细词结果扩大到整个宽主题的所有文件。
- 页面按2026-10-20最新要求包含“文件处理”“主题模糊搜索”“QA汇总”三个主模块。文件页面使用实际数据，无文件时统计为 0；仅显示文件总数、正式主题和已入库 QA 三项统计。
- 中英同一次生成、同一次审核，分 zh/en 两条记录保存，内部配对 ID 不增加正式列；每批最多3组。审核须检查两个版本的事实与翻译等义，绑定两版 hash；任一版变化须重新审核。旧单语保留，不自动补译。页面按组对照，文件处理列表、文件详情和主题模糊搜索页均按2026-10-19最新要求暂时移除中英语言筛选；总表、文件及主题下载均包含范围内全部已入库语言记录。
- QA 正式字段严格为 `input, thinking, output, source, image, language`。`source` 为 `本地路径|page-页码-seg-段号|较宽正式主主题`，定位必须能回查。图片题的 `image` 指向实际保存的图片路径；文字题为空。仅在真正读取图片后生成视觉问答。
- 2026-10-15 用户明确服务器部署要求：服务器已有统一资料库，按2026-10-20补充要求包含PDF与PNG/JPG原图，应用从库中选择、登记和读取文件，不要求再次上传，也不把原始 PDF 再持久复制进项目目录。资料库可能保存 PDF 内容，也可能保存文件位置；实际对接方式部署时确定。处理记录保留稳定来源标识、版本/hash 与真实页段，确保可回查；内部文字证据、真实图片、QA 和任务数据仍需保存到配置的持久存储；按2026-10-16补充要求，PDF文字不另存TXT/MD或纯文字页图片。原文件变更或删除须识别，不能悄悄让旧证据指向新内容。此项基础目录引用已于2026-10-21实现，真实服务器接入和部署仍待验收；详见文末最新记录。若来源不是本地路径，后续明确 source 第一段的兼容映射，不虚构路径或静默更改六字段契约。
- 问题必须可独立理解，依据原始证据，优先领域知识而非文档概述、页码、文件格式或其他导航信息；不能扩大研究结论的适用范围。候选经 AI 审核与人工核对后才正式入库。
- 应用的 AI 调用统一通过公司 GLM 网关 `https://www.dmxapi.cn/v1`，已验证的文本及视觉模型名为 `glm-5.3-flash-guan`。密钥绝不写入源码、网页、日志、测试或聊天。
