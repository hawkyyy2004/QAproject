## 产品目标与已确认规则

- 新人投入 PDF、图片、CSV 或文本文件后，系统解析证据、生成简短梗概、归入一个或多个较宽正式主题，再生成与主题对应的问答候选。每篇约 5 组中英双语知识点，完整时为 10 条六字段记录；质量不足时说明原因，不编造补齐。
- 主题优先复用、合并同义、避免把每个关键词都建成正式主题；细分词单独用于模糊搜索。搜索应能由上位词发现相关主题及其实际涵盖文件，同时避免把细词结果扩大到整个宽主题的所有文件。
- 页面只有“文件处理”和“主题模糊搜索”两个主模块。文件页面使用实际数据，无文件时统计为 0；仅显示文件总数、正式主题和已入库 QA 三项统计。
- 中英同一次生成、同一次审核，分 zh/en 两条记录保存，内部配对 ID 不增加正式列；每批最多3组。审核须检查两个版本的事实与翻译等义，绑定两版 hash；任一版变化须重新审核。旧单语保留，不自动补译。页面按组对照，导出可选中英全部、仅中文或仅英文。
- QA 正式字段严格为 `input, thinking, output, source, image, language`。`source` 为 `本地路径|page-页码-seg-段号|较宽正式主主题`，定位必须能回查。图片题的 `image` 指向实际保存的图片路径；文字题为空。仅在真正读取图片后生成视觉问答。
- 2026-10-15 用户明确服务器部署要求：服务器已有统一 PDF 资料库，应用从库中选择、登记和读取 PDF，不要求再次上传，也不把原始 PDF 再持久复制进项目目录。资料库可能保存 PDF 内容，也可能保存文件位置；实际对接方式部署时确定。处理记录保留稳定来源标识、版本/hash 与真实页段，确保可回查；提取的文字、真实图片、QA 和任务数据仍需保存到配置的持久存储。原文件变更或删除须识别，不能悄悄让旧证据指向新内容。此为后续部署需求，当前尚未实现；本次只记录约定，不改程序。若来源不是本地路径，后续明确 source 第一段的兼容映射，不虚构路径或静默更改六字段契约。
- 问题必须可独立理解，依据原始证据，优先领域知识而非文档概述、页码、文件格式或其他导航信息；不能扩大研究结论的适用范围。候选经 AI 审核与人工核对后才正式入库。
- 应用的 AI 调用统一通过公司 GLM 网关 `https://www.dmxapi.cn/v1`，已验证的文本及视觉模型名为 `glm-5.3-flash-guan`。密钥绝不写入源码、网页、日志、测试或聊天。

## 2026-10-15 双语改造

新增配对表及任务列的幂等迁移；数量分别报告双语组数与记录条数。每篇默认目标5组（完整10条），源证据语言不限制目标语言。审核失败不得用人工确认绕过；“重新核验本组”只调用本组审核，仍使用同一队列/租约。旧未入库单语需重新核验后提交。真实小样本脚本为 `scripts/check_bilingual.py`，记录在隔离 runtime/bilingual-check，测试耗时不能外推正式论文。

本次38项本地测试通过。公司GLM在隔离合成资料上，从头处理5组/10条实测28.72秒（未入库）；3组对照仅生成/审核：单语11.68秒、双语14.16秒，多约2.48秒，不能承诺零增量或推广到正式论文。首轮非法JSON重试的历史记录保留，最终格式约束已收紧。详见README双语验证节；真实合成PNG的双语1组实测25.08秒，分类/生成/审核均传实际图片，复杂论文图表的双语质量仍待验收。

## 2026-10-15 本地轻量主题语义搜索

用户已明确授权本地开源 Embedding，作为主题搜索的公司模型约定例外；生成和审核仍调用公司 GLM。新增 `semantic.py`（缓存/空闲调度）与 `embedding.py`（独立 ONNX CPU 子进程），BGE small 中文 INT8 权重约24 MB，模型与分词文件仅在 runtime。安装依赖后运行 `scripts/setup_search_model.py`，固定版本、SHA-256 记录在 config/embedding-model.json。新机器无需 Embedding API/key。

第二模块原包含/关键词检索保留且精确名称优先；`/api/search/semantic` 返回独立的最多5条相似主题推荐，按真实关联主题过滤，点击后再查资料。忙时只读缓存，未缓存查询等待；有文件 queued/running 时不启动嵌入，已启动的在 PDF worker 处理前终止。模型仅在子进程按需加载，结束释放；不承诺未经正式对照实测的 PDF 零影响。主题更新使用元数据版本扫描与可恢复缓存，尚非通用 outbox。

真实本地模型在9个隔离合成主题通过验证，报告 `runtime/search-check/1792050704832025000/report.json`；首轮索引0.6462秒、新查询任务0.2081秒、30次缓存读取P95 2.175毫秒，不含前端轮询等待或PDF处理。正式库实际5个主题上，搜“海洋探测”可推荐“海洋观测”；没有注入演示主题。质量阈值0.65待扩大语料验证；专业短词/跨语言效果未完整验收。

本次全套49项测试通过，浏览器已验证精确命中、相似排序、点击推荐查看关联资料与无直接匹配时的语义召回；界面截图在 runtime/search-check/ui/semantic-search.jpg。
