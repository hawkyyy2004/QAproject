# 前端调用说明：两个页面怎样完成工作

前端是你看到的页面，负责收文件、显示进度和结果。后台是处理资料的工作台，负责保存证据、调用公司 GLM 和核验问答。

可以把它想成一个收件窗口：你递交资料，窗口把资料交给后台；窗口会问“做到哪一步了”，然后把结果展示给你。搜索时，窗口把你输入的词交给后台，后台查找对应资料。

## 文件处理

| 你的操作 | 页面交给后台什么 | 页面拿回什么 |
| --- | --- | --- |
| 打开应用 | 获取本地会话和配置状态 | 密钥是否已配置、模型名称、文件限制；不返回密钥 |
| 选择或拖入文件 | 文件内容和当前工作区 | 文件编号、是否重复、是否成功加入队列 |
| 等待处理 | 每隔 2.5 秒查询正在处理的记录 | 阶段、批次进度、梗概、主题、候选数量和错误原因 |
| 点击一份文件 | 文件编号 | 原始证据、六字段 QA、核验说明和本次各阶段耗时 |
| 展开图片 | 图片编号 | 后台读取的真实图片 |
| 确认入库 | 候选编号、版本和点击入库操作 | 提交结果；审核无效、证据或版本变更则拒绝，无需额外勾选 |
| 导出 QA | 当前工作区及可选文件/主题编号 | 按所选中英全部/仅中文/仅英文下载已入库六列 CSV，候选不会混入 |

对应实际接口依次为 `/api/bootstrap`、`/api/imports`、`/api/documents?summary_only=true`、`/api/documents/{id}`、`/api/assets/{id}`、`/api/candidates/{id}/approve` 和 `/api/export`。

文件列表和搜索只返回摘要、分类与数量，不携带整篇原文、图片清单及候选答案；点击文件时才取详情，证据图片延迟加载。PDF 默认页数不限，保留每份 25 MB 大小限制；后台逐页解析并分批调用 GLM。纯文字页直接读取文字用于 QA，不另导出文本文件或显示为页截图；空白页不存图，实际图像/图表区域才保存并按图片编号预览。扫描件无法直接读出文字时仍保留真实图像证据。

页面只上传一次资料。处理期间查询进度不会重复让 GLM 生成问答。初版在浏览器页面内轮询；刷新页面后重新读取持久记录，不依赖页面一直打开。

## 主题模糊搜索

输入词语后，页面将它发送到 `/api/search`。后台先看正式主题及别名，再看细分关键词与文件的关联。返回正式主题、命中的方向和对应文件。

例如，搜“数学”展示它下的示例资料；搜“圆锥曲线”只展示确实关联圆锥曲线的文件，不把所有数学资料都一起返回。圆锥曲线作为检索方向，不自动建立一个新的正式主题或 QA 表。

初版已实现中文短词、名称、预设别名和具体关键词匹配，暂未实现任意自然语言的向量语义检索。输入时稍等 0.35 秒再发查询，避免每敲一个字都发出请求。

## 多模态调用发生在哪里

文字与图像视图都保留真实页段；每篇文字约3–5组、图片0–2组，合计目标5–7组中英双语知识点（10–14条记录），不为凑数补题。图片批次在文字完成约3组后参与生成，不再等文字耗尽全篇配额；没有适合视觉考点时用文字补到约5组。扫描页和视觉问答仍交给 GLM 读取真实图片，纯正文截图不充当图片题。图片由后台保存，后台把真实图像内容交给 GLM。页面的图片预览只是让你检查证据。QA 的 image 保存真实路径，页面按图片编号取图，两者用途不同。

你填写的 `.env.local` 只由后台读取。页面不读取这个文件，也不直接向公司网关发送 key。

正式页面只显示实际投入资料，首页三个统计框横向排列，分别为文件总数、正式主题、已入库 QA，没有文件时均为 0。合成样例留作内部测试，不出现在正式统计和搜索中。请求过时或候选版本改变时丢弃旧结果，避免显示已经失效的数据。

代码入口：`web/app.js` 管理页面动作；`src/qaproject/app.py` 接收请求；`src/qaproject/pipeline.py` 执行处理；`src/qaproject/glm.py` 统一调用公司接口。

## 中英双语核对

每个新知识点在一次生成中返回中英两版，文件详情按同组展示，分别为 zh/en 两条六字段记录；source/image 共用同一原始证据。共同审核同时检查事实、语言与翻译等义，不另外翻译全文。人工分别确认入库或排除，完整入库两版才算一组双语。首页仍只有三个统计框，已入库 QA 按条数统计，文件列表另显示完整双语组数。

需检查的组可点“重新核验本组”，发送候选编号及 expected_hash 至 `/api/candidates/{id}/rereview`；仅处理该组，未通过时按同一原证据修订两版并重新审核，不重复全文分析；通过后可直接点确认入库。文件级“优化问答并重新审核”调用 `/api/documents/{id}/optimize`，复用已冻结证据与合格问答。最终交付只含审核及入库校验通过的记录，仍失败的草稿留存处理记录并报告不足。总表保留导出语言选择；文件详情“六字段 QA”右侧移除语言下拉框，“导出已入库”包含该文件中英全部记录，不继承列表语言筛选；主题结果导出中英全部；后台 `/api/export` 的 language 选 zh、en，不传则全部。历史单语有明确标注，不自动补译；旧未入库候选需先重新核验。


## 完整图片预览

区域裁剪已按用户要求移除。详情通过 `/api/assets/{id}?mode=live` 延迟读取已保存完整图片，点击可查看原分辨率；同页文字仍展示。原 `/api/assets/{id}/figures` 及其图片接口已移除，不再生成或读取裁剪缓存。新解析保存完整含图页；既有冻结证据及QA图片引用不改写。其他文件处理、审核、搜索和导出接口保持原流程。
